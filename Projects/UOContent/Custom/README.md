# Custom

Contenuto di gioco nuovo (item, mobili, quest, sistemi) specifico di questo fork va qui, in file nuovi.

Non esistendo questa cartella nell'upstream ModernUO, i file al suo interno non entrano mai in conflitto durante i merge di sincronizzazione (`git merge upstream/main`).

Per le modifiche a file *esistenti* (stock content o `Projects/Server`), vedi invece [`custom-docs/CUSTOM_CHANGES.md`](../../../custom-docs/CUSTOM_CHANGES.md).
